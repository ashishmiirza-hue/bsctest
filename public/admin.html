Setup: deploy the billing contract

This is done once. Your wallet sends the deployment transaction, so no private key is stored anywhere. The wallet you connect becomes the contract owner: only it can charge users and change settings. You need a little BNB for the network fee.

On-chain safety: max per single charge

An extra guard: the most any one charge can pull, on top of each user's own limit. Set it to cover your biggest expected single bill. 0 means no extra cap (a user's remaining limit is still the hard bound). Changing it is an owner transaction.
